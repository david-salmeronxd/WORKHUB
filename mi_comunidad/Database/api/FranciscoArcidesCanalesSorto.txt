5. EVIDENCIA DEL PIPELINE CI/CD FUNCIONANDO
----------------------------------------------------------------
https://github.com/francisco-canales/ProyectoModulo8/actions
Pipeline en .github/workflows/deploy.yml (GitHub Actions).

Jobs:
  1. test   -> npm ci + npm test + verificación de .env.example
                (se ejecuta en cada push a main y en cada PR a main)
  2. deploy -> se ejecuta solo en push a main, tras pasar `test`,
                dispara el despliegue en Render vía API


Evidencia de la validación local (mismo comando que ejecuta el pipeline):

  $ npm test
  ✔ GET / responde 200 con los endpoints
  ✔ GET /health responde JSON con status
  ✔ Ruta inexistente responde 404
  tests 3, pass 3, fail 0
